# RFC Workflow

## Goals
- ลดความเสี่ยงก่อน implement งานใหญ่
- ให้ทีมรีวิว trade-off ได้ง่าย

## Template
1. Context
2. Problem Statement
3. Proposed Solution
4. Non-goals
5. Rollout Plan

## Checklist
- มี owner ชัดเจน
- มี metric ก่อนและหลัง rollout
- มี fallback plan
